## 2025-02-12 - EC2 Hardening: IMDSv2 and EBS Encryption Invariants
**Vulnerability:** Default AWS EC2 configurations do not enforce metadata service v2 (IMDSv2) or root block device encryption, leaving deployed servers (like the Ubuntu FastAPI test server) exposed to SSRF token extraction and unencrypted data leakage. Additionally, HCL syntax errors (`value` instead of `default` for variable definitions) prevented OpenTofu from validating and securing the configuration during static checks.
**Learning:** Security controls such as IMDSv2 (`http_tokens = "required"`) and volume encryption must be declared explicitly in Terraform/OpenTofu configurations to maintain compliance with defense-in-depth principles. Furthermore, static validation checks (`tofu validate`) are critical to catch syntax drift before security-hardened modules are committed.
**Prevention:** Enforce mandatory `metadata_options` with `http_tokens = "required"` and explicit `root_block_device` blocks with `encrypted = true` for all EC2 instance resources. Establish automated `tofu validate` checks in pre-commit workflows to verify HCL compliance.
